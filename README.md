
# EdTech SQL Analytics Project

## Project Overview

This project analyzes an EdTech training institute's operations using SQL Server.

The project covers:

- Data Import & Database Design
- Joins and Aggregations
- Subqueries & CTEs
- Window Functions
- Views
- Indexes
- Stored Procedures
- User Defined Functions
- Exception Handling
- Triggers
- Business Analytics

## Tools Used

- SQL Server
- SSMS / Azure Data Studio
- Excel

## Business Questions Solved

- Revenue Analysis
- Marketing ROI
- Cost Per Acquisition
- Enrollment Trends
- Trainer Performance
- City-wise Demand Analysis
- Course Performance

## Key Insights

- Revenue showed consistent growth across months.
- Maharashtra and Telangana contributed the highest registrations.
- Programming and AI courses generated strong revenue.
- Trainer satisfaction scores remained above industry average.
- Marketing channels differed significantly in acquisition efficiency.
